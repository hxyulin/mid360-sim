# Material/edge measurement validation

See the [workflow guide](../../docs/guide/material-validation.md) for collection,
input schema, synthetic checks and interpretation. These standard-library tools
need no simulator, ROS runtime, private decoder or recorded dataset. No calibrated
material/beam model is fitted or installed into the sensor.
